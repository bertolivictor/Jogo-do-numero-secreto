# ❓ Jogo do Número Secreto

Bem-vindo ao **Jogo do Número Secreto**! Um projeto divertido e desafiador desenvolvido durante um curso de iniciação em lógica de programação. Este jogo testa suas habilidades de adivinhação e estratégia enquanto você tenta descobrir o número secreto gerado aleatoriamente. A cada tentativa, você recebe dicas para se aproximar da resposta correta. Será que você consegue acertar com o menor número de tentativas? Vamos descobrir!

---

## 👨🏻‍🏫 Como Funciona

1. **Número Secreto Gerado**: Ao iniciar o jogo, o sistema gera um número aleatório entre 1 e 100 (ou outro intervalo definido).
<img src="https://github.com/user-attachments/assets/3626c86a-0ce4-429c-9ca2-6aa6b87ea026" width="1200px" />

2. **Faça Seu Chute**: Insira um número no campo de entrada e clique em "Chutar".
<img src="https://github.com/user-attachments/assets/c1121048-1db5-4b76-8639-299241e096f2" width="1200px" />

3. **Dicas Valiosas**: A cada chute errado, o sistema te dá uma dica:
   - 🟢 **Maior**: O número secreto é maior que o seu chute.
   - 🔴 **Menor**: O número secreto é menor que o seu chute.
<img src="https://github.com/user-attachments/assets/0eb59e9b-adbc-4def-ba11-1aca9f840748" width="1200px" />

4. **Vitória!**: Quando você acerta o número, uma mensagem de parabéns é exibida, mostrando quantas tentativas você usou.
<img src="https://github.com/user-attachments/assets/ef59c718-ebeb-40b7-a104-001f5736350a" width="1200px" />

5. **Reiniciar o Jogo**: Clique em "Novo Jogo" para zerar as tentativas e gerar um novo número secreto. O desafio recomeça!
<img src="https://github.com/user-attachments/assets/3626c86a-0ce4-429c-9ca2-6aa6b87ea026" width="1200px" />
